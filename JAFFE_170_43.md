# Fixed JAFFE 170/43 protocol

This borrows AdaFER's split sizes, not an exact reproduction of its unpublished file split. Class-stratified random image split, seed 1314; subjects can overlap. Test counts in CAST order: Surprise 6, Fear 7, Disgust 6, Happy 6, Sad 6, Angry 6, Neutral 6. Train counts: 24,25,23,25,25,24,24.

Create the manifest once, before experiments:

```bash
python jaffe_split.py --root /workspace/ttt/code/data/jaffe_retinaface_256 --output splits/jaffe_170_43_seed1314.json --seed 1314
```

The generator refuses to overwrite an existing file. Keep this exact manifest across all baselines. Files are not moved. Pass `--jaffe_split_manifest splits/jaffe_170_43_seed1314.json` to train.py; without the flag the older full-pool protocol remains available.

Adaptation views, threshold statistics and every target-derived training state use only the 170 adaptation images; adaptation labels are -1. The 43 images are evaluated only once after the predetermined last adaptation round. There is no target validation/best selection. A copy of the manifest is stored in checkpoints. True filename labels are used for split construction and final evaluation only.

Reuse a RAF-only source checkpoint, never a checkpoint already adapted on all 213 JAFFE images. Keep the RAF preprocessing unchanged. Existing 213-image results are a different protocol and cannot be directly compared. A single error changes 43-image accuracy by 2.33 percentage points; do not retune the split or seed based on test performance.
